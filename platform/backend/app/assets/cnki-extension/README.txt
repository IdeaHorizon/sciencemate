ScienceMate 知网检索：旧版 Chrome 扩展兼容说明

正常使用不需要安装本扩展。在 ScienceMate 的「资讯 → 学术搜索」中提交问题即可检索中文文献；进度、检索结果和重试都在搜索页查看。

已配对的兼容客户端显式提交本机扩展任务后，可发送唤醒信号，或在扩展中点击“执行一次”处理一个任务。遇到验证或报错，在该浏览器完成验证后，从平台重试该任务，再唤醒扩展。扩展传回标题、作者、摘要等题录，不下载 PDF；关闭浏览器时无法执行检索。

升级到扩展 0.2.0 会清除旧版定时轮询；重启 Chrome 或完成配对不会开始采集。仅升级平台不会更新手工安装的旧扩展，不再使用旧客户端时可以停用它。
