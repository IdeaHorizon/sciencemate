ScienceMate 知网本机采集（Windows / Linux / macOS Chrome）

1. 解压此文件夹。在本机 Chrome 打开 chrome://extensions，开启“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择包含 manifest.json 的 sciencemate-cnki 文件夹。
3. 在 ScienceMate 设置 → 知网本机采集中生成连接码。
4. 点击 Chrome 工具栏中的本扩展，填写平台网页地址及连接码，点击“连接平台”。
5. 在平台搜索页选择“知网（本机 Chrome）”检索；在设置页添加每日采集任务。
6. 如提示验证，点击扩展“打开知网 / 完成验证”，在自己的 Chrome 中处理。

浏览器可以最小化。登录 Cookie 不会上传。扩展只上传文献 index，包含可取得的
摘要、关键词、作者、日期等，不下载 PDF。不需要开启远程调试端口。
关闭 Chrome 或电脑休眠时采集暂停；再次启动后按平台保存的页码接续，已采集
记录会复用缓存。主动关闭采集标签页会暂停任务，可在扩展中点击“继续采集”。
扩展每 30 秒检查待办；平台页面发起搜索时会立即唤醒。每日任务每 24 小时采集
一次，首次覆盖近 12 个月，后续保留 31 天重叠窗口以减少日期模糊造成的遗漏。
知网可能要求登录、验证码或限制访问；扩展会暂停并提示，不能保证全天无人值守。
本扩展尚未上架 Chrome 应用商店。解压目录请保留，移动后需要重新加载扩展。
