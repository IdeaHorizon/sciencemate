## 1. 第一性原理：科学要求什么

判决每一堵墙，只问它服务于下面哪一条科学要求——一条都对不上的，就不是科学
基础设施，是官僚仪式。

**S1 可复现（出处不可伪造）**。科学记录的全部价值建立在「记录如实」上：做了什么、
输入是什么、出来什么。伪造 status、伪造出处、伪造凭据的行为必须机械禁止——
这是普查里的 B 类真墙，科学上承重，保留。

**S2 诚实报告（可证伪性的前提）**。科学不要求每项检查都通过，**只要求通过/失败/
未做三种状态如实可见**。「图未经 VLM 审查」写明即可；「引用清单与 plan 不一致」
记录即可。强迫检查通过才许前进不是科学要求——如实标注才是。推论：**检查照跑，
判决取消**——620 堵墙里大多数的检查逻辑有真实探测价值（它们确实能发现异常），
错的是检查结果自动附带的「不许过」。降格 = 检查存活为见证/义务，拒绝分支死。

**S3 判断权属于科学家与同行评审，不属于流程**。真实的科学没有任何机构禁止你
「在数据不全时写论文」——审稿人裁决它。科学的质量闭环是 judgment-by-peers
（本平台 = referee 终审，wangd 拍板的命门），不是 mechanical pre-clearance。
事前审批链（approved plan 才许执行/安装/搜索、approve 才许入稿）是官僚制，
不是科学。行动中的判断权归 agent（继续/补偿/换路/停下/问人），终审权归
referee 与用户。

**S4 预注册是承诺不是牢笼**。预注册防的是 HARKing/p-hacking，其科学执行方式是
**偏离必须申报**（amendment / declared deviation），不是偏离不可能发生。真实的
registered-report 期刊全部接受带披露的偏离。未申报的偏离 = 账变假 = B 类；
申报了的偏离 = 合法科学行为。所有 prereg 一致性墙照此降格。

**S5 探索与发表是两种状态**。对着异常数据画图看一眼是好科学（探索）；把异常
数据标成正常图放进论文是坏科学（发表）。语义正确性检查（生存曲线必须非增、
相关矩阵必须对称）在探索路径上只许当信号，在发表路径上化为必须应答的义务——
但两条路径上都不许直接拒绝渲染：**看不见图的科学家连调试都做不了**。

**S6 资源与安全是实验室管理，不是科学，但同样真实**。沙箱、密钥、销毁确认、
token/轮次熔断（A 类）保留——它们不判断科学质量，只守护不可逆边界。

## 2. 三档判决与判据

对普查出的每条 D 逐条裁决，三档：

### 档一：彻底删（检查与拒绝一起死，零替代）
满足任一即入此档：
- **纯仪式**：要求逐字抄写固定断言而框架不验真伪（relational_grammar 的
  provenance 逐字闸）；字数下限闸（reasoning ≥N 字符——验不出诚意，意图放进
  schema description）。
- **重复抄件**：同一要求在多层各执行一遍（approved 图包要求三处抄写）——最多
  留一条义务，其余删（一个问题一个真相源）。
- **任意审美阈值**：≤40 节点、≤6 分组、标签 ≤64 字符——模型能判的别硬编码
  （feedback_framework_makes_the_symptom 第二半句）。
- **预测失败**：框架预测「你会失败」而拒绝执行（ABI 预检）——让现实拒绝，
  C 类如实报错本来就在。
- **部分成功判全废**：附属交付物失败把已成功主产物整体判 error。
- **30 天零命中且以上任一嫌疑**：连辩护机会都没有的死重。

### 档二：降格为义务（检查存活，拒绝死）
判据：检查逻辑对 S1-S5 中某条有真实探测价值，但执行方式违反 S2/S3。
降格的机械含义（统一，不逐条发明）：
- 检查照跑，结果**写进产物元数据/validation 报告**（如实可见，含失败）；
- 未过项生成**义务**（core/obligations collector——按效应聚合，620 墙预计收敛
  为 30-40 个 collector）；
- agent 必须**应答**义务：修复 / 补偿 / 让步（附理由，框架机械佐证能佐证的
  部分）/ 停下问人。自主档按自己的推荐继续，让步异步呈报；
- 让步永久进账本 + 收尾清单 + 稿件局限节（QC judge 只读可见句），referee
  终审逐条裁决；
- 让步改不了 status——产物永远如实写明哪些检查没过（S1 兜底）。

### 档三：保留 / 升格 / 呈裁（预计 10-20 条）
- 二审发现实为 A/B 误分：如「逐字节相同输入不许原样重派」实为算力熔断（A）、
  「job 未终态不许标 finalized」实为账本真实性（B）。
- 治理设计项，需 wangd/owner 显式拍板：裁决权分离（取证者不裁决自己的取证）、
  KB org 晋升三查、domain_registry 人批背书。

### 边界复核（防误杀）
每条「删」在落刀前再问一遍普查用的那把尺：**若放行并如实记录，账还真吗？
行为可逆吗？** 任一为否 → 升 B/A，不删。

## 3. 命中后果判据（高频墙专用）

30 天内开火 ≥3 次的墙，逐墙看命中后的 transcript：撞墙后 agent 的下一步是
（a）合规修正并成功——墙起了引导作用（但要问：一条不拦的提示是否同样有效）；
（b）原地重试同一调用 / 换路绕行 / 空转——骚扰墙；（c）报 blocked 放弃——
死路墙。b、c 占比高的墙，无论意图多正确，执行形态判失败。
