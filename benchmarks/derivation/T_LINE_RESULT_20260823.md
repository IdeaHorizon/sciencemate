# T 线：理论-实验闭环跑通，时间戳链机械可查

> 2026-08-23。纲领 §Q1.5 的 P1，也是 derivation 与 prover 实验室的分野所在。

## 主张

> 理论预测**先于实验被冻结** —— 任何 prover 实验室给不出这个。

一句主张，除非能机械核对，否则跟 marketing 没区别。这一趟把它做成了可查的。

## 两步，两个 run，真实时间戳

| | run | 时间 | 产出 |
|---|---|---|---|
| 1 | derivation | 冻结于 **18:20:23Z** | `2/log(1+sqrt(2))` = 2.269185314213022 |
| 2 | experiment | 开跑于 **18:22:35Z**（晚 131s） | T_c^MC = 2.266448 ± 0.006456 |

**对账**：|T_c^MC − T_c^theory| = **0.002737 < 0.02**（0.42σ）✓

### 第 1 步：derivation（20 步链，8 条活假设）

Kramers–Wannier 自对偶 → `sinh(2K_c)=1` → `kT_c/J = 2/ln(1+√2)`。
账本 **15 verified / 19 numerically_supported / 1 failed**。

那条 failed 是模型**自己发现的笔误**（`exp(-2*asinh(...))` 丢了 `/2`），
按收尾闸给的合法出口 1 处理：记录笔误 → 修正 → 重验。
**收尾闸的三条出口文案第一次在真实笔误上被用对。**

### 第 2 步：experiment（Wolff + Binder 累积量）

L ∈ {8,12,16,24}，T ∈ [2.20,2.34] 步长 0.01，7 个交叉点无权平均。
三份产物全冻结（raw_results / clean_results / experiment_log，SHA-256 校验）。

## 机械核对：`scripts/verify_prediction_precedes_experiment.py`

```
  ✓ 推导已冻结且有冻结时间     frozen_at=2026-08-22T18:20:23.881942+00:00
  ✓ 实验开跑晚于推导冻结       18:20:23 → 18:22:35（相隔 131s）
  ✓ 理论值出现在实验记录里     2.269185314213022（2/log(1+sqrt(2))）
✅ 时间戳链成立
```

**它会说「不」**：阴性对照实跑过 —— 拿推导自己的 run 当实验传进去，
第 2 条立刻红（run_start 18:07 早于 frozen_at 18:20）。
一个只会说"是"的核对脚本等于没有核对。

## 两个刻意的方法论选择

**1. 不用 E2E v26 的现成 Ising 数据。**
平台 2026-08-13 真跑过这个课题，有完整 MC 结果，用它对账最省事 ——
但**那批实验早于今天的推导，时间戳链是反的**，拿它演示"预测先于实验"
就是摆拍。真跑一次新的：小规模 Wolff 三个尺寸 0.3 秒，完全跑得动。
精度低不影响闭环成立（论文级精度是另一件事）。

**2. v26 的教训写进闭合条件。**
那次的真实结论：**同一批数据，加权拟合给出 refuted(2.8σ)、无权给出
supported(1.17σ)**。所以预注册不能只冻阈值，还要冻**分析方法** ——
事后选拟合方案等于事后选结论。

于是有了 `FIT_SCHEME` 条目，实验如实兑现：
> "unweighted mean **declared before run** (script docstring + experiment_log §2)
>  and executed exactly; no weighting applied"

以及 `THEORY_PROVENANCE` 条目，实验自己记下了对照值的出处与冻结时间。

## 这一趟证明了什么

- **跨模态互证真的能跑通**：derivation 出预测 → experiment 检验，
  两个节点各自的纪律都在场，账本能对上。
- **预注册纪律自然延伸到理论-实验协作**：现有循环（Analysis ⇄ 取证多轮）
  一行没改就支持了这个时序。
- **主张变成了可查的东西**：不是"我们记得是先推导的"，是两份落盘记录的
  时间戳 + 一个会说不的核对脚本。

## 没做的

- 完整 project 模式（本次两步是 standalone，靠 fixture 传递上游）——
  Analysis 的终态裁决与 curator 沉淀未跑。
- 更高精度的 MC（当前 0.42σ 已够验证闭环，论文级需要更大 L 与更多样本）。
