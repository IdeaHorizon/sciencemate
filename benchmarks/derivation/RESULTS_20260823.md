# 首轮对照结果：harness 到底值不值那些 token

> 2026-08-23。16 题 × 2 臂，模型两边都是 **deepseek-v4-flash**（唯一变量是 harness）。
> 纲领 `docs/DERIVATION_NODE_DESIGN_20260822.md` §Q1.5，方法 `benchmarks/derivation/README.md`。

## 结果

| 指标 | A0 裸模型 | A1 derivation 节点 |
|---|---|---|
| 结果正确率 | 91% (10/11) | **100% (12/12)** |
| 假命题识别率 | 100% (4/4) | 100% (4/4) |
| 正命题裁决正确 | 100% (12/12) | 100% (11/11) |
| 假设完备率 | 98% (n=16) | 100% (n=15) |
| 证伪理由完整度 | 88% (n=4) | 88% (n=4) |
| 未验披露 | 100% (16/16) | 100% (14/14) |
| **★ 验证可核验性** | **0% (n=16)** | **99% (n=15)** |
| 平均轮次 | 1.0 | 24.9 |
| 平均工具调用 | 0 | 38.2 |

（n 小于 16 是因为判不了的挂了人工复核**不计分** —— 见文末。）

## 结论：预测被证实，而且是以最有信息量的方式

设计时写在 README 里的预期是「**harness 赢在信任维度，不在正确率**」。
结果比预期更干净：

**1. 正确率两边都很高（91% vs 100%）—— harness 不是靠算得更准取胜。**
这些是教科书题，flash 裸跑就能做对。19 题次里 A0 只错一个（阻尼共振峰宽多了
一个 √3 因子）。**如果价值主张是"让模型算得更准"，这套 harness 不值那 38 次
工具调用。**

**2. 假命题识别率两边都是 100%。**
四道埋错题（E[S]=σ 的 Jensen 偏、谐振子修正符号反、√ 次可加缺非负条件、
方差可加缺不相关条件）flash 裸跑全部证伪成功。**这一维没有区分度** ——
对这个难度的错误，模型自己就抓得住。

**3. 唯一压倒性的差异是验证可核验性：0% vs 99%。**

这不是"A0 不会验证"，是**A0 的验证声称无法被任何人独立核验**：

    A0  "正则系综密度算符…是基本结论，未在此重新推导"   ← 自述，无法定位、无法查
    A1  unverified_steps = ["S1","S8"]                 ← 框架从账本现算，虚报不了

A1 的每一条"已验证"都带式子指纹（probe），能反查本 run 的验证账本。
A0 说"我验过了"时，你只能选择信或不信。

**这正是纲领里"产品是可信的推导记录，不是被证出来的定理"的实体。**
harness 买到的不是正确率，是**可审计性**。

## 成本

A1 每题约 25 轮、38 次工具调用、5-14 分钟；A0 一轮 2-4 分钟。
**贵 5-10 倍。** 这个代价换来的是可核验性，不是正确率 ——
值不值取决于这份推导要不要被别人信。一次性问答不值，
进论文/进 KB/被下游引用的推导值。

## 判分器改了三轮才可信 —— 这是本轮最该记的事

首次判分：A0 36% / A1 29%。**如果我信了这张表，会得出"harness 让模型算得
更差"的假结论。** 三轮下来，全部是判分器与题目的问题，**没有一个是模型算错**：

| 轮 | 修的是什么 | 修前 → 修后 |
|---|---|---|
| 1 | 主结果从"末步 claim 的等号右边"猜（模型在链尾加了附加路线） | A1 0% → 29% |
| 2 | γ/β/ζ 撞 sympy 内建函数，解析直接崩（连自己和自己都判不了） | 36%/29% → 43%/50% |
| 3 | 符号定义（x≡ħω/kT）、别名（lam/lambda）、Eq 包装、题目歧义 | 43%/50% → **91%/100%** |

三轮的共同形状：**判据比被判的东西更不可靠**。而误判的方向全是"把对的判成
错的" —— 比误判成"harness 赢"温和，但同样让结论不可信。

配套的纪律：判不了的**标 needs_review 不记 0 分**（矩阵记法 `X.T`、
Python 关键字当符号名这类），与工具侧的 `inconclusive` 是同一条 ——
**算不出来就说算不出来。**

## 需人工复核（12 条，不计分）

- 表达式判不了 4 条：矩阵记法（`X.T`、`Inverse`）与 `p_i = ... , beta = ...`
  这种多式子提交，超出简单比对能力。
- `unverified_steps` 为空 6 条：分不出"全验过了"与"没披露"。
  A1 可查账本，A0 只能人判 —— 这个不对称本身就是数据。
- A0 提到可复现的验证方式但无结构化证据 2 条：给 A0 的公平通道。

## 这轮没有回答的 —— 以及后来的答案

三条开放项，两条**已经查清并证否**（详见
`MEASUREMENT_BOUNDARY_20260823.md`）：

| 开放项 | 后续 | 结果 |
|---|---|---|
| 更难的题上识别率还是 100% 吗 | M3：5 道 L2 假命题 | **仍是 100%** —— 命题级埋错测的是模型知识，不是 harness 机制 |
| 多次重复的方差 | M4：3 题 × 4 次 × 2 臂 | **两臂都 100% 正确、100% 一致、零翻转** |
| 更强模型会不会拉平 | 未跑 | 仍开放 |

根因同一个：**这批任务对 flash 太稳定**。30 个 A1 run、283 个验证过的式子，
只有 3.5% 被判 failed，每 run 平均 0.33 次自犯错 —— 低频且随机，
探路量级测不出统计显著性。

**因此本报告的主结论收紧为**：

> harness 唯一被实验证实的价值是 `verifiability`（0% vs 99%），
> 而且它是**结构性的、与题目难度无关**。
> 抓错价值真实存在（30 run 抓到 10 次），但当前难度下测不出显著性。

`假命题识别率` 与 `同题一致性` 降级为阴性对照（证明模型没被 harness 搞坏），
不再作为价值证据。
