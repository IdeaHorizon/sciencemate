# 测量的边界：两轮都撞同一堵墙，该停止加码了

> 2026-08-23。M3（L2 加难度）与 M4（同题重复测方差）的合并结论。

## 两轮尝试，同一个结果

| 轮 | 假设 | 设计 | 结果 |
|---|---|---|---|
| M3 | 「假命题识别率能体现 harness 价值」 | 5 道 L2 假命题（柯西 CLT / 极限积分交换 / 两两独立 / 矩阵幂 / 黎曼重排） | **两臂 5/5，理由完整度都 100%** |
| M4 | 「同题重复的方差能体现」 | 3 道长题 × 4 次 × 2 臂 | **两臂 100% 正确、100% 一致、零翻转** |

两个假设都被**证否**。

## 根因是同一个：这批任务对 flash 太稳定

把 30 个 A1 run 的账本合起来算：

```
  run 数            30
  验证过的式子      283
  被判 failed 的    10  (3.5%)
  有自犯错的 run    7/30  (23%)
  每 run 平均       0.33 次
```

**模型自己犯错是低频随机事件。** 要在统计上观测「抓住 ⇒ 结果更对」，
按 0.33 次/run 的发生率，需要的样本量远超探路规模 ——
而且方差实验那 9 个 run **一次都没犯**（首轮 12 题犯了 5 次）。
低频 + 随机 = 探路量级测不出来。

## 停止加码，因为再加也是同一堵墙

M3 加了难度、M4 加了重复，都没绕过"题太容易"这个根。第三次的正确选择不是
再加一轮，是**承认边界并写下什么条件才测得出**：

要观测抓错价值，任务得满足其一：
- **链足够长**（当前最长 17 步；错误率随链长复利，50+ 步才会明显不稳）
- **模型知识边界之外**（教科书题预训练里全有，冷门/前沿推导才会出错）
- **存在似真的错误路径**（多条路可走且部分是死路，而不是一条直路）

这三条都不是"再写几道题"能满足的，需要重新设计任务来源。

## 这两轮不是白做的

它们**排除了两个假设**，让纲领的价值主张更清晰而不是更模糊：

> **harness 唯一被实验证实的价值是 `verifiability`（0% vs 99%）。**

而且这一维是**结构性的、与题目难度无关**：A0 的验证声称永远无法被独立核验，
不管题有多简单或多难。抓错价值真实存在（30 个 run 里抓到 10 次，
其中 T 线那次是模型自己发现 `/2` 笔误后修正），但**在当前难度下测不出
统计显著性** —— 这两句话都得说，只说前半句是夸大，只说后半句是抹掉。

## 对 benchmark 的处置

- `假命题识别率` **降级为阴性对照**（证明模型没被 harness 搞坏）
- `同题一致性` 保留脚本（`analyze_variance.py`），但**不再作为主指标** ——
  留给将来有难题时用
- **主指标只剩 `verifiability` + 成本**，这是诚实的

## 方法论：预写标准第二次生效

M3 的 commit 里写着「两种结论都得如实报，不能靠继续加题来凑出想要的差异」，
M4 的分析脚本里焊着「两臂一致性都是 100% 时说明这批题太稳定 —— 那也是结论」。

两次都正好撞上那个"不想要"的结果，而预先写下的话让它没法被绕过。
**如果判断标准是看到结果之后才定的，这两轮很可能会变成"再加五道题"。**
