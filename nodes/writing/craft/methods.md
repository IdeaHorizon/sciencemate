# 方法

方法节回答一个问题：别人拿着这一节能不能复现你的实验。

## 结构（按对象类型调整）
1. 研究对象与配置：对象是什么、为什么选它们、关键参数表格化。
2. 实验设计：因素与水平（拓扑 × 策略 × 算法 × 网络），矩阵规模，命名规则。
3. 设置与参数：工具与版本、硬件近似参数、网络与链路参数、生成方法。参数只写卷宗里有的，写不出来源的不写。
4. 指标与统计口径：每个指标怎么定义、怎么聚合、比较子集怎么选。
5. 精度或校准：有校准实验就写清对象、仿真值、实测值、误差。

## 写法
- 表格优先：配置参数、拓扑描述、网络模式、链路参数各一张三线表，正文只解释表读不出来的东西。
- 一个小节一个主题，小节标题是名词短语。
- 描述建模边界时写「未建模」什么，写在一处，不在每段重复。
- 方法里不下结论、不讨论结果。

## 不要
- 不写「本文采用……进行了……」的空话开头，直接进入对象。
- 不在方法里替读者判断哪个方案好。
- 不出现工具的运行细节（命令、脚本名），除非它是可复现性必需的参数。

## 输出格式
以 \section{方法} 开头，小节用 \subsection，表格用 table 环境加 booktabs（\toprule \midrule \bottomrule），每张表有 \caption 与 \label{tab:...}，并在正文用「表~\ref{tab:...}」引用。
