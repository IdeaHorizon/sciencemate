# 随安装包提供的期刊目录

`journal_metrics.sqlite3` 是运行时只读的期刊快照，包含 22,396 本期刊、47,839 条名称/缩写别名，以及已有的 ISSN、eISSN、NLM 标识和指标。没有论文、PDF、封面图片、用户订阅或账号凭据。

本次快照：19,726 本有 2024 年影响因子，21,771 本有 2025 年中科院分区；年份保存在数据中，缺失值保留为空。数据沿用现有 `suqingdong/impact_factor` 导入库和本地 CAS 分区表，不把历史指标标成最新指标。原始电子表格及其他参考材料不随公开源码导出。

安装后自动读取这份库，搜索命中时无需访问 Crossref。库外期刊仍走在线查询。用户已导入的 `literature/reference/journal_metrics.sqlite3` 优先，`HARNESS_JOURNAL_METRICS_DB` 显式配置也保持优先；在线搜索不会重写这份快照。离线导入仍写用户数据目录，升级不会覆盖用户自己的库。

Windows、macOS 桌面安装包、跨平台更新包和 Linux 运行时都带相同文件。公开树导出仅放行本文件和这份数据库，不放行整个参考资料目录。桌面打包发现缺少数据库时会失败，避免再次发布不完整的安装包。

维护时在仓库根目录执行：

```bash
python -m scripts.package.build_journal_catalog /path/to/journal_metrics.sqlite3
```

导出会新建数据库页，仅复制已知期刊表、别名表和指标年份，去掉个人源文件路径等元数据，保留源库原样。生成后将数据库与代码一起提交，由正常发版流程分发；不在用户启动时下载或建库。
