# E2E 双盲审阅量表

两位审阅者不知道系统名称。每项 0–2 分；无法判断标 `NA`，不猜测。

| 维度 | 0 | 1 | 2 |
|---|---|---|---|
| 检索审计 | 无查询/来源信息 | 有部分关键词或来源 | 查询、来源、筛选与失败均可追溯 |
| 书目真实性 | 有不可核验或幻觉引用 | 大多可核验但有明显错误 | DOI/URL 可核验，重复已说明 |
| 证据绑定 | 结论无论文支撑 | 只有部分结论可回溯 | 关键结论和分歧均绑定具体论文 |
| 摘要保真 | 生成内容伪装原摘要 | 有来源说明但混用 | 原文、外源补齐、AI 总结明确区分 |
| 分类 | 无分类或明显误归 | 有主题但边界不清 | 允许多标签，类别与证据一致 |
| 局限披露 | 不说明缺口和失败 | 只泛泛说明 | 区分研究空白、数据缺失和工具失败 |
| 可复用产物 | 仅一段文字 | 有论文清单 | 有可重读索引/报告/状态与路径 |

全文、图片、持久缓存单列为 `not_offered / available / verified`，不与共同检索分相加。
