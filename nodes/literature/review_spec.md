# Literature 审核规范（survey_report / literature_evidence_package）

先读当前 research_question、mode 和实际交付，核查来源真实、内容保真及本次用途的证据充分性。
服务调用本身不自动触发独立 post-node flow；本规范供独立审核或消费方按需核查。

## 按用途选择范围

- targeted_lookup：核对具体问题是否由相关且可核实的来源回答；少量决定性来源可以足够。
- contradiction_check：核对支持与反对材料的条件、版本和范围，辨别表面与实质矛盾；
  不只选一侧制造一致，也不强求本来不存在的反方来源。
- method_lookup：核对方法、参数与适用条件来自实际来源，建议实现与已报道事实分开。
- landscape：评估主线、经典与近期工作、相关异见、检索范围和遗漏风险；
  不以论文总数代替覆盖度，也不因文献少要求凑数。

## 专业核查

1. 引用真实性与含义：抽查决定性来源及具体段落，不只查标题或 KB ID。
   错误归因、相反方向的引用和无来源数字属于内容问题。
2. 主张与证据：区分作者报告、领域共识、检索者综合与推测；数值、条件和边界与来源一致。
   缺摘要或全文不能用模型生成内容冒充。
3. 覆盖与选择：范围与当前任务相称；核心缺漏指出具体工作及影响，不笼统要求补齐全部文献。
   已完成检索可复用，有新矛盾再定向补查。
4. 空白与不确定性：区分研究空白、检索不足和内部 KB 登记缺口；根据语义判断，
   不因出现某个措辞直接判诚信失败。
5. 交付与来源记录：索引和报告与来源一致。author wiring 等登记按当前模式核对，
   登记问题与科学结论错误分开；未登记进 KB 不等于论文不存在。

来源字段不可得时，核查是否记录来源、尝试和影响。决定性证据不足应限定主张或补证；
非关键缺失可以披露后使用，不自动触发完整调研。不要将定向服务升级成完整综述。

## 输出与建议

使用 compose_review_critique 记录 review_scope、unverified_checks 和具体 concerns。
可用 coverage / citation_fidelity / evidence_support / honesty / traceability 描述评分；
非适用项不计，verdict 根据实际缺陷与用途判断，不按平均分或引用数量自动映射。
关键主张失实或无支持时建议修正；可选扩展只作建议，不授权扩大研究。
Reviewer 不改报告或来源；调度器和消费方选择行动并保留未解决限制。
