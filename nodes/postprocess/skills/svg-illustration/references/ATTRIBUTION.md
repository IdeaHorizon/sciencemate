# 参考图来源与署名

本目录 5 张 PNG 复制自 AutoFigure 项目（`autofigure/references/paper/`），
按 AutoFigure 仓库根 `CITATION_AND_ATTRIBUTION.md` 的要求署名（MIT 许可）。

用途（移植方案 A · 路径 1 定案）：这些图**不在运行时注入**任何模型调用。
它们已被预转译成文字风格规格，冻结在本 skill 的 SKILL.md 正文（风格规格节）
——主 reasoning LLM 是纯文本链路，原图到不了创作者手里，转译文本才是
创作者实际读的形态。原图留存此处仅作备用与溯源（二期可选：挪作 witness
端风格锚点，仅当端到端实测发现风格漂移时启用）。
